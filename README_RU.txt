STAR CLASH — сервер онлайн-матчей (начальная версия)

Что есть:
- Socket.IO сервер;
- очередь подбора игроков: пара игроков попадает в комнату;
- события движения, выстрелов и окончания матча;
- проверка формата данных и ограничение частоты событий;
- /health для проверки работоспособности.

Важно:
Это серверная заготовка, а не готовое подключение к опубликованному сайту. Текущая версия игры на Netlify сама по себе НЕ подключена к этому серверу. Для настоящего боя надо добавить Socket.IO-клиент в игру и связать серверные события с движением, попаданиями и здоровьем. Не доверяйте клиенту результаты/награды в производственной игре — урон должен рассчитываться сервером.

Запуск на компьютере:
1. Установить Node.js 18 или новее.
2. В папке проекта выполнить: npm install
3. Запустить: npm start
4. Проверить: открыть http://localhost:3000/health

Публикация:
Разместить папку как Node.js Web Service на хостинге, который поддерживает постоянный процесс Node.js и WebSocket (например, Render). Build command: npm install. Start command: npm start. Затем взять HTTPS-адрес сервиса. Netlify Static Hosting не запускает этот сервер.

После публикации сервера нужно подключить его URL к клиенту STAR CLASH. Два пользователя должны открыть обновлённую клиентскую игру и нажать «Онлайн»; только тогда подбор сможет соединить их через разные сети.
