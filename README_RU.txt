STAR CLASH ONLINE — инструкция для GitHub с телефона

В корне репозитория должны лежать:
- server.js
- package.json
- index.html

Загрузите/замените эти три файла в корне GitHub-репозитория. Не загружайте ZIP вместо файлов.
После Commit changes Render должен автоматически запустить новое развёртывание.

Render:
Build Command: npm install
Start Command: npm start

Откройте домен Render — там появится игровое меню. Для теста онлайн-матча откройте сайт в двух вкладках/на двух устройствах и нажмите «Найти игрока».
Это прототип, а не полная готовая коммерческая игра.
