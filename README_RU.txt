STAR CLASH 3D — меню + режимы

В корень GitHub-репозитория загрузи/замени файлы: index.html, bots.html, online.html, server.js, package.json.

index.html — 3D-меню и бой с ботами; после кнопки ИГРАТЬ появится выбор режима.
bots.html — та же 3D-игра, открытая напрямую.
online.html — страница поиска онлайн-игрока.
server.js — серверные маршруты и Socket.IO.

После Commit changes дождись статуса Live в Render. Проверка: /health. Для онлайн-боя нужны два подключённых игрока.
