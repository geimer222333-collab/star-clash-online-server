STAR CLASH — объединённый прототип

Содержимое:
- index.html — главное меню с выбором «Игра с ботами» или «Онлайн».
- public/bots.html — прежняя игра с ареной и ботами.
- public/online.html — текущая страница онлайн-поиска соперника.
- server.js — Node.js / Socket.IO сервер.

Render настройки:
Build Command: npm install
Start Command: npm start

Как применить в GitHub с телефона:
1. Скачайте ZIP и распакуйте его.
2. В репозитории star-clash-online-server добавьте/замените index.html и server.js в корне.
3. Создайте папку public и положите туда bots.html и online.html.
4. package.json должен быть в корне.
5. Commit changes. Render автоматически запустит новое развёртывание.

Важно: это объединяет меню и две страницы-прототипа. Онлайн-поиск и соединение Socket.IO есть, но полная синхронизация боя (движение, попадания, здоровье) ещё не реализована. Firebase-аккаунты, кристаллы и лидерборд в этот пакет не подключены.
